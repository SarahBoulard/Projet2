Objet : Scraper Books to Scrape, version bêta et pipeline ETL

Bonjour Sam,

La version bêta du scraper est prête. Le code est sur GitHub : https://github.com/SarahBoulard/Projet2
Les données extraites sont dans l'archive ZIP jointe. Le README explique comment installer et lancer le script.

Le programme suit déjà les trois étapes d'un pipeline ETL :

1. Extract (extraction) : le script lit la page d'accueil de Books to Scrape, récupère les 50 catégories, parcourt toutes leurs pages (pagination comprise) puis visite la page de chaque livre. Il en extrait les dix informations demandées.

2. Transform (transformation) : les données brutes sont nettoyées avant d'être enregistrées. Le stock « In stock (22 available) » devient 22, la note en étoiles devient un chiffre de 1 à 5, les adresses relatives des images deviennent des URL complètes, et chaque image est renommée avec l'UPC du livre.

3. Load (chargement) : les données sont écrites dans un fichier CSV par catégorie, daté du jour de l'exécution, et les images sont rangées dans un dossier par catégorie.

Pour passer de cette bêta à un vrai suivi des prix, on pourrait :
- lancer le script automatiquement à intervalle régulier (tous les jours par exemple) 
- charger les données dans une base de données plutôt que dans des CSV, pour comparer facilement les prix d'une date à l'autre 
- convertir les prix en nombres pendant la transformation, pour pouvoir les calculer et les trier 
- ajouter d'autres librairies en ligne, en écrivant pour chacune la partie extraction et en gardant le même format de sortie
